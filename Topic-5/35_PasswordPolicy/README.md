# 35 PasswordPolicy

All Java files in this folder belong to the default package. This exercise is
self-contained and requires only JDK 11 or later.

From this folder:

```sh
javac *.java
java Main
```

`Main.java` demonstrates the classes with sample data.

## Prerequisites

Use classes, constructors, encapsulation, this, composition, toString() and the explicitly explained equality operations. Do not use exceptions or additional utility libraries.

## Input and behaviour

Use a non-negative minimum length. Required uppercase letters are A-Z, lowercase letters are a-z, and digits are 0-9. Detect these ranges with character comparisons.
