# Classroom exercises — Java solutions

Each numbered folder is a self-contained exercise. All classes use the default
package (there are no `package` declarations). No other exercise, external
library, Maven or Gradle project is needed.

Use a JDK 11 or later. Compile and run each folder separately; several exercises
have a class named `Main`. In an IDE, create one Java project per exercise,
without `module-info.java`, and keep its classes in the default package.

From the repository root, for example:

```sh
cd Classroom-exercises/01_Breaking_Down_Seconds
javac *.java
java BreakingDownSeconds
```

Exercises 31–37 include a `Main.java` demonstration alongside their model classes.
Interactive examples prompt for input; other examples use values in `main` that
you can edit. These introductory solutions assume inputs within the exercise's
intended domain and numeric range.
