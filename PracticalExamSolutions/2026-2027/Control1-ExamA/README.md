# Control 1, model A — 26 October 2026

[Handout](ExamA.pdf) · Solution: [Program.java](Program.java)

`nextPrimePalindrome` returns the smallest prime palindrome greater than `n`. It uses two helper methods: `isPrime` and `reverse`.

## Compile and run

From this folder, with a JDK on your `PATH` (Windows, macOS and Linux):

```text
javac -encoding UTF-8 Program.java
java -cp "." Program
```

The program reads `n` from the keyboard. For example, `31` gives `101`.

For terminal setup and paths containing spaces, see the
[repository instructions](../../../README.md#compiling-and-running-java-exercises).
