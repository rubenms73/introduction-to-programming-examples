# Control 1, model D — 28 October 2026

[Handout](ExamD.pdf) · Solution: [Program.java](Program.java)

`nextAbundant` returns the smallest abundant number greater than `n`. It uses the helper method `sumOfProperDivisors`.

## Compile and run

From this folder, with a JDK on your `PATH` (Windows, macOS and Linux):

```text
javac -encoding UTF-8 Program.java
java -cp "." Program
```

The program reads `n` from the keyboard. For example, `12` gives `18`.

For terminal setup and paths containing spaces, see the
[repository instructions](../../../README.md#compiling-and-running-java-exercises).
