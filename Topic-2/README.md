# Topic 2: Expressions, Types and Simple Programs

Each exercise is self-contained and uses the default Java package. Open an
exercise folder for its compile and run instructions. Requires JDK 11 or later.
The commands in each example README support Windows (PowerShell and CMD),
macOS and Linux. Compile inside one example folder at a time.
Exercise numbers match the classroom exercise handout.

| Exercise | Run after compiling this example |
| --- | --- |
| [01 Breaking down seconds](01_Breaking_Down_Seconds/) | `java -cp "." BreakingDownSeconds` |
| [02 Minimum change](02_Minimum_Change/) | `java -cp "." MinimumChange` |
| [03 Distance between two points](03_Distance_Between_Two_Points/) | `java -cp "." DistanceBetweenPoints` |
| [04 Invoice with discount and VAT](04_Invoice_With_Discount_and_VAT/) | `java -cp "." InvoiceWithDiscountAndVat` |
